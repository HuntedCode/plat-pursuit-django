Owner-only surfaces include it; the endpoints behind it refuse anybody else's run regardless. `compact` drops the label below `md:` and keeps an aria-label, for a dense row like My Challenges' finished list, where a word per row would crowd out the run's name on a phone. The glyph is Lucide's share-2, the one the franchise and tag pages already use for sharing. Expects: run (a Challenge), compact (optional bool). {% endcomment %}
