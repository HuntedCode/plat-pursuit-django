{% comment %} THE MARK, anywhere a name renders. One object across the whole site: the name in the mark's colour (the pp-supname primitive) plus the mark's glyph -- stars for supporter levels exactly as the storefront previews them, the wrench for staff, the shield for moderators. Precedence was decided at WRITE time (users/services/marks.py -> Profile.display_mark); this template never chooses, it only renders what it is handed. Unmarked names render BARE -- no wrapper. A .pp-markname span here would make the text an anonymous flex item, which cannot ellipsize, so every truncating container site-wide would hard-clip the ~99% of names that carry no mark. Callers that need a hook have their own element. `--sup-delay` (from the tag's optional index) offsets the flow per row; `--svc` names hold still -- the flow is the bought register's signature (see supporter.css). {% endcomment %}{% if mark %}{{ name }}{% if mark.kind == 'supporter' %}{% for _ in mark.star_range %}{% endfor %}{% elif mark.key == 'staff' %}{% elif mark.key == 'mod' %}{% endif %}{% else %}{{ name }}{% endif %}
