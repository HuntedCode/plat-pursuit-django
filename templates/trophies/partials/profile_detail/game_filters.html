{% comment %} The Games tab's toolbar, rebuilt 2026-08 to the browse standard. It was the last pre-rebuild filter bar on the site: DaisyUI throughout (`bg-white/[0.03]`, `select-bordered`, `peer-checked:btn-primary` chips), a `
` for the advanced filters, and an explicit Filter button. It carried `data-browse-form`, so it auto-applied selects and checkboxes -- but none of the SEARCH affordances, because those are opted into by MARKUP and it had none of the hooks. Now the same vocabulary Browse Games uses (`.pp-toolbar-card` / `.pp-gbrowse__*` / `.pp-bgal__*`), which buys the shared behaviour rather than just the look: * `data-live-search` + `data-page-search` -> debounced live filtering, the spinner, Escape-to-clear, the clear button, and the global `/` and Cmd-K focus shortcuts * `PlatPursuit.filterPanel` (wired in profile_detail.html) -> the animated drawer, the active-filter count badge, the results dim, and open-on-load when something is already filtering What it deliberately does NOT take from Browse Games: the sticky mini-bar (that belongs to a scrolling PAGE, not a tab panel inside one) and "I'm Feeling Lucky" (a catalogue-discovery action, meaningless over one hunter's own library). `hx-target="#tab-results"` rather than `#browse-results`: this is a tab panel, and the results div it swaps is the tab's own. The `tab` hidden input rides along so a filter swap stays on Games. {% endcomment %}
