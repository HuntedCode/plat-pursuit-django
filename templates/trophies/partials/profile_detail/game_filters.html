{% comment %} The Games tab's toolbar -- reduced 2026-08 from ten controls to four. This tab is a RECORD of what somebody has played, not a browse page, and it had inherited Browse Games' discovery apparatus wholesale: genre and theme pickers, community rating / difficulty / fun ranges, a time-to-beat range, a shovelware toggle, and eight `show_*`/`hide_*` community flags that no template ever rendered. Those answer "what should I play next" -- a question about a catalogue. Nobody arrives at a hunter's profile to shop. Four controls remain: search, status, sort, platform. **Status replaced four fields.** `game_has_plat`, `plat_earned`, `is_100` and the completion range were all asking one question -- how far did they get -- and this file previously argued they were three independent axes that could not collapse "into one status chip row that would have to invent combinations." That was wrong, and the card is what shows why: it already renders a five-state completion bar, so the states existed and were named. The options here ARE those states, which means picking one fills the wall with a single bar colour and the filter teaches you to read the card. **No drawer.** Four controls are a toolbar, not a `filterPanel` collapse -- so the advanced panel, its toggle and its active-filter count are gone. `data-browse-form` and `data-live-search` stay, because the search affordances (debounced live filtering, the spinner, Escape-to-clear, the clear button, the global `/` and Cmd-K shortcuts) come from `browse-filters.js` and are opted into by MARKUP, entirely independent of the drawer. Options come from `sort_options` / `status_options` in the context rather than a bound field's `.choices`: both are CharFields so an unknown value can be coerced instead of invalidating the form (see `ProfileGamesForm.clean_sort`). Badges and Ratings already feed their toolbars the same way. `hx-target="#tab-results"` rather than `#browse-results`: this is a tab panel, and the results div it swaps is the tab's own. The `tab` hidden input rides along so a filter swap stays on Games. {% endcomment %}
