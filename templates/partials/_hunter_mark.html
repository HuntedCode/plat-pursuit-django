{% comment %}THE HUNTER'S MARK (Page Principles rule 1): what the viewer has done with a game, on its cover. A progress bar along the cover's bottom edge, and "Platinum" or their percentage on the art just above it. Shared by the browse game cards and a game list's cards (review AU-02), so a game reads the same wherever you meet it. Expects `pg` (`has_plat`, `progress`; a ProfileGame or `gamelists.services.viewer_progress`'s best version) and `chase` (the game has a platinum to chase). Renders nothing for a game the viewer has not started. Lives inside `.pp-gcard__cover`, which positions it. The fill colour encodes the state (5): plat + 100% = platinum; plat earned but under 100% (post-plat DLC) = muted teal; 100% without a plat = green; a plat available but not yet earned = amber (the hunt); progress with no plat to chase = slate.{% endcomment %} {% if pg and pg.progress > 0 %} {% if pg.has_plat %}Platinum{% else %}{{ pg.progress }}%{% endif %} {% endif %}
