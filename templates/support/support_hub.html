STRIPPED BACK TO THE HEADER (2026-08-20), deliberately. Earlier versions carried the whole argument -- an evidence band, a roadmap strip, a signed note, a perks table, a supporter wall -- and each rebuild kept repainting sections that had never been agreed. So the page is the header alone while the ask gets settled, and the rest gets built back one piece at a time. The copy for those sections is not lost; it is in the git history of this file and headed for /support/roadmap/ and About. THE HEADER IS SPLIT: the statement on the left, the ask on the right in a decorated box. That puts the decision above the fold rather than below several sections of argument. THE BOX IS AMOUNT-FIRST. You pick a number and the page tells you what that makes you, rather than comparing six named rows -- borrowed from Blender's Development Fund widget. Entirely CSS-driven off `:has(:checked)`: both the cycle switch and the amount grid are real radios, so all of it works with JavaScript off. The script only adds the `is-active` class the shared `.pp-switch` look keys on. THE LADDER IS PLACEHOLDERS. Buttons are inert until its twelve Stripe prices and twelve PayPal plans exist. The POST handler, success_url, subscribe_success and both webhooks underneath are untouched, so switching it on is wiring a button to a contract that already works. The view forces placeholders off in live mode, so production can never render a dead buy button. Everything sits on the standard card chrome. Nothing on this site sets prose directly on the page substrate, and an earlier version of this page did, which is most of why it read as foreign. {% endcomment %} {% block content %}
