{% comment %} Plat card -- the share image for a game completion. Landscape only, 1200x630. TWO VARIANTS, one layout. `variant` is 'platinum' (the game defines a platinum, so finishing the default group means they popped it) or 'full' (no platinum defined; the list is simply finished). They differ in accent, mark and label -- never in structure -- so they read as siblings. WHY IT LOOKS LIKE THIS - 1200x630 is the OG/Twitter/Discord embed ratio, and that is where these actually get seen: ~450px wide in a Discord preview. Every size here is chosen to survive at ~37% scale. If an element wouldn't read at that size it isn't on the card. That is the whole reason the old card's dense stat grid, badge rail and rating pills are gone. - The hunter is the subject, not the game: identity strip on top (avatar, name, the title they're wearing), then the completion. A share is "look what I did". - Game art BACKS the card, it never leads it. Concept.get_landscape_url() resolves to an IGDB screenshot -> artwork -> PSN bg_url -> nothing, so the art is uncurated and often absent. The card must be complete without it, which is why the ground is a designed gradient by default and the scrim is an INNER layer (the renderer replaces the ground with `!important` when a theme is picked, so a scrim baked into the ground would be blown away and text would land on raw art). INLINE STYLES, HEX ONLY Playwright renders via page.set_content() in an about:blank origin: no stylesheet, no custom properties. So the --pp-* token VALUES are ported by hand. Keep this map in sync with input.css: --pp-bg-0 #05080c --pp-text #f0f6fd --pp-bg-1 #181d23 --pp-text-dim #9da5b1 --pp-bg-2 #232a31 --pp-text-mute #8a939f --pp-bg-3 #2f363f --pp-border #404853 --pp-primary #27ebfe (platinum variant accent) --pp-accent #ff9350 (100% variant accent) TYPE: the same two-voice pairing as the site -- Bricolage Grotesque (--pp-font-display) for the things you read first (username, variant label, game title, tallies), Inter (--pp-font-body) for labels and meta. Both are embedded by the renderer from static/fonts/; a face that isn't in that directory cannot render here at all, so keep the stacks to those two families. Context: see core/services/completion_card_service.get_card_data + api/shareable_views.build_card_context. {% endcomment %}
