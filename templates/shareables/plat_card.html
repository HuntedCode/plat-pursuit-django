{% load static humanize custom_filters %}{% comment %} Plat card -- the share image for a game completion. Landscape only, 1200x630. TWO VARIANTS, one layout. `variant` is 'platinum' (the game defines a platinum, so finishing the default group means they popped it) or 'full' (no platinum defined; the list is simply finished). They differ in accent, mark and label -- never in structure -- so they read as siblings. WHY IT LOOKS LIKE THIS - 1200x630 is the OG/Twitter/Discord embed ratio, which is where these get seen: ~450px wide in a Discord preview. Sizes are chosen to survive at ~37% scale. That constraint governs the TYPE SCALE, not the amount of information -- the card is zoned (identity / completion / proof / attribution) so density lands as scannable rows rather than mush. - The hunter is the subject, not the game: identity strip on top (avatar, name, worn title, career totals), then what they did. A share is "look what I did". - NO COMMUNITY STATS, deliberately. Game.plats_earned_count / played_count / full_completion_count / monthly_players_count / total_earns_count are all denormed and free to read, and they were considered for this card. They describe the GAME; the card is about the hunter's achievement. A community rarity is actively worse than the PSN global one it would sit beside: our population is people who own the game AND signed up to a trophy tracker, which selects hard for completionists, so it reads systematically MORE COMMON. "2.4% globally, 11% here" tells the reader the achievement is less impressive among people like them. - THE CARD IS ALSO AN ADVERT. It travels to people who don't have an account, so the brand block is a real mark -- logo, wordmark, and the domain -- not a whisper in the corner. It is the second thing you see after the game. - Game art BACKS the card, it never leads it -- and it is a THEME, not a fixture. Painting the backdrop unconditionally (as this did at first) put it on top of whatever ground the theme set, so all six options rendered identically. The ground is now owned entirely by the theme: the designed gradients, or one of the art grounds the renderer composites from `concept_bg_path`. Concept.get_landscape_url() resolves to an IGDB screenshot -> artwork -> PSN bg_url -> nothing, so the art is uncurated and often absent, and the card has to be complete without it. - The scrim is an INNER layer for the same reason: the renderer replaces the ground with `!important`, so a scrim baked into it would be blown away and text would land on raw art. INLINE STYLES, HEX ONLY Playwright renders via page.set_content() in an about:blank origin: no stylesheet, no custom properties. So the --pp-* token VALUES are ported by hand. Keep this map in sync with input.css: --pp-bg-0 #05080c --pp-text #f0f6fd --pp-bg-1 #181d23 --pp-text-dim #9da5b1 --pp-bg-2 #232a31 --pp-text-mute #8a939f --pp-bg-3 #2f363f --pp-border #404853 --pp-primary #27ebfe (platinum variant accent) --pp-accent #ff9350 (100% variant accent) Tier dot colours are lifted from --color-trophy-* -- see TIER_DISPLAY in completion_card_service. TYPE: the same two-voice pairing as the site -- Bricolage Grotesque (--pp-font-display) for the things you read first (username, wordmark, variant label, game title, tallies), Inter (--pp-font-body) for labels and meta. Both are embedded by the renderer from static/fonts/; a face that isn't in that directory cannot render here at all, so keep the stacks to those two families. Context: see core/services/completion_card_service.get_card_data + api/shareable_views.build_card_context. {% endcomment %}
{% comment %}Scrim: an INNER layer, so it survives a theme replacing the ground with `!important`. Tuned for a DESIGNED ground, not for raw art. It was originally set for the latter (0.95 -> 0.64) and crushed all four gradient grounds to the same near-black -- picking a different one changed almost nothing. The art grounds don't need that strength from here anyway: the renderer already lays its own 0.45-0.55 black over an image before this layer ever applies, so heavy values here were darkening art twice and everything else once too many.{% endcomment %}
